# Iraqi Arabic Sales Dialogue Dataset

A large synthetic dataset of Iraqi (Baghdadi-based) Arabic dialogue, centered on
retail sales, haggling, and everyday conversation.

> النسخة العربية متوفرة بالكامل [بالأسفل](#النسخة-العربية) — Arabic version available in full below.

## What this is

**210,832 template-generated conversations, of which 171,601 (81%) are exact-unique
message sequences**, spanning 20 topical categories in colloquial Iraqi Arabic. The
core of the dataset (10 categories) is retail sales dialogue — price inquiry,
haggling, warranty, and closing a sale — generated by `scripts/generate_iraqi_data.py`.
A further 10 categories, added later, cover everyday and social domains (health,
education, government, restaurants, transport, sports, family, occasions,
neighborhood life, work).

**The data is entirely synthetically generated by template and generation scripts —
it is not transcribed from real speakers**, with one exception disclosed in
[Data provenance](#data-provenance-and-a-disclosure) below.

## Why this exists

Iraqi Arabic is severely under-represented in NLP. Most public Arabic conversational
data covers Modern Standard Arabic or Egyptian/Levantine dialects. This dataset gives
a model exposure to Iraqi vocabulary and syntax (`شلونك` not `كيف حالك`, `بيش` not
`بكم`, `أكو` not `يوجد`) in a domain — sales negotiation — that general Arabic
corpora don't cover at all.

## Honest sizing — read this before the file table

Two numbers matter, and they are not the same:

- **210,832** — total conversation records across the 21 JSON files. This is a
  **template-expanded** count: the generator combines a bank of names, products,
  prices, and phrasings, so many records differ only in a substituted price or name.
- **171,601** — conversations that are **exactly unique** message-for-message
  (identical role/content sequences collapse to one). That is an overall repetition
  ratio of **1.23×**. Do not headline the larger number as if it represents 210,832
  independent conversations; it does not.

This exact-duplicate measure is the one this README leads with because it is
mechanically reproducible from the files themselves (hash each conversation's
message list, count distinct hashes) — it does not depend on a normalization
heuristic you have to trust.

## Data schema

Each entry in the category files is a JSON object with a `messages` list:

```json
{
  "id": "electronics_sales_0001",
  "category": "sales_electronics",
  "dialect": "iraqi_arabic",
  "messages": [
    { "role": "user", "content": "أريد لابتوب Asus Core i7 بس غالي علي" },
    { "role": "assistant", "content": "بس قبل ما تروح، شوف هذا الموديل الثاني، عندنا تقسيط بدون فائدة على 3 أشهر" },
    { "role": "user", "content": "يعني أدفع شكد بالشهر؟" },
    { "role": "assistant", "content": "مقدم 299,000 والباقي قسطين متساويين" }
  ]
}
```

Prices are in Iraqi Dinar (IQD). Fields: `id`, `category`, `dialect`, `messages[]`
(each with `role` and `content`).

## File structure

```

                               shared with the iraqi_words_finetuning repository

  iraqi_train_01_electronics.json  … iraqi_train_20_work.json
  train.json                       separate Q&A-format file (Question/Answer/Topic), 10,000 entries
data/                          Deduplicated JSONL training/validation splits (v4–v10),
                               plus supplementary sets (catalog-grounded, extraction,
                               greetings). Prepared from the category files above by
                               scripts in scripts/.
scraped_data/                 Raw marketplace listing data used to seed
                               iraqi_train_04_cars_plus_scraped.json — see
                               Data provenance below.
scripts/                      Generation scripts (generate_iraqi_data.py and
                               later variants) and data-prep utilities.
*.ipynb                        Fine-tuning / merge notebooks (Gemma).
IRAQI_DIALECT_REFERENCE.md     Extended dialect notes.
AA.md                          Iraqi-language prompt templates and analysis notes
                               used during dataset iteration (not training data).
```

## Usage

Load a category file directly:

```python
import json

with open("iraqi_training_data/iraqi_train_01_electronics.json", encoding="utf-8") as f:
    data = json.load(f)

print(len(data))            # 10000
print(data[0]["messages"])
```

Load a deduplicated JSONL split with 🤗 `datasets`:

```python
from datasets import load_dataset

ds = load_dataset("json", data_files="data/iraqi_train_v8_part*.jsonl", split="train")
```

Regenerate the category files from scratch (uses `word.json` as its vocabulary source):

```bash
python scripts/generate_iraqi_data.py
```

## Data provenance and a disclosure

Every category file is generated from templates and a curated vocabulary/name bank —
**with one exception you should know about before using this data**:

`iraqi_training_data/iraqi_train_04_cars_plus_scraped.json` contains 10,832 records,
of which **832 carry a `real_data` field and a `source` URL pointing to specific,
real listings on `sooq.iq` and `opensooq.com`** (real car brand/model/year/mileage/
price/city, and a direct link to the original listing). These are not synthetic —
they were scraped from live marketplace listings and used as grounding facts for the
surrounding dialogue. The same underlying scraped listings, with their source URLs,
also live in `scraped_data/`.

This means:

- The claim "entirely synthetic" does **not** hold for this one file — 832 of its
  10,832 records (7.7%) embed real third-party listing data and links.
- The listings were public marketplace posts at scrape time, but redistributing them
  verbatim (including direct URLs to individual ads) is a different thing than
  generating synthetic text, and downstream users should treat this subset
  differently — e.g. exclude `real_data`/`source` fields, or drop the 832 records,
  if you need a strictly synthetic dataset.
- No phone numbers, seller names, or other personal contact information were found in
  either the scraped files or the category files during review (a handful of
  placeholder-pattern phone numbers such as `07801234567` and `07800000000` appear in
  three category files and are templated placeholders, not real numbers).

If you need a purely synthetic subset, use `iraqi_train_04_cars.json` (10,000 fully
generated records) instead of `iraqi_train_04_cars_plus_scraped.json`, or filter out
records with a `real_data` key.

## Limitations

- **Synthetic generation.** With the disclosed exception above, conversations are
  produced by scripts and templates seeded with curated vocabulary and name banks —
  not transcribed from real speakers. They reflect plausible dialogue patterns, not
  verified natural speech, and lack the disfluencies of real conversation.
- **Template repetition.** 210,832 records collapse to 171,601 exact-unique message
  sequences (1.23× overall). Repetition is uneven: the original 10 sales categories
  stay under 1.2×, while several later general-topic categories reach 1.4–1.77×. See
  the per-file table above before assuming uniform diversity.
- **Single-domain bias.** The dataset's core strength is retail sales negotiation;
  the 10 non-commercial categories added later are comparatively less developed and
  more repetitive.
- **Dialect coverage limited to specific regional varieties.** The base dialect is
  Baghdadi Arabic, with vocabulary drawn from `word.json` covering additional Iraqi
  cities (Mosul, Basra, Najaf, Karbala, and others), but Baghdad usage dominates;
  southern and northern Iraqi varieties are under-represented.
  Non-Baghdadi dialects are not distinguished in the `dialect` field — every record
  is tagged `iraqi_arabic` regardless of which city's vocabulary it draws on.
- **No human evaluation of naturalness.** No native-speaker rating of fluency,
  realism, or dialect authenticity has been performed on this corpus; only automated
  and self-review checks were applied during generation.
- **Not safety-filtered for deployment.** No adversarial, toxicity, or refusal
  training is included.
- **Prices are time-bound** and reflect market conditions around 2025–2026.

# مجموعة بيانات محادثات البيع باللهجة العراقية

مجموعة بيانات واسعة ومولّدة صناعياً لمحادثات باللهجة العراقية (بغدادية الأساس)،
متمحورة حول البيع بالتجزئة والتفاوض والحديث اليومي.

## نظرة عامة

**210,832 محادثة مولّدة بالقوالب، منها 171,601 (81%) بتسلسل رسائل فريد حرفياً**،
موزعة على 20 تصنيفاً باللهجة العراقية الشعبية. نواة المجموعة (10 تصنيفات) هي حوار
بيع بالتجزئة — السؤال عن السعر، التفاوض، الضمان، وإغلاق الصفقة — مولّدة بواسطة
`scripts/generate_iraqi_data.py`. عشرة تصنيفات إضافية، أُضيفت لاحقاً، تغطي مجالات
يومية واجتماعية (الصحة، التعليم، الحكومة، المطاعم، النقل، الرياضة، العائلة،
المناسبات، حياة المحلة، العمل).

**البيانات مولّدة صناعياً بالكامل عبر سكربتات وقوالب — وليست منقولة من متحدثين
حقيقيين**، باستثناء واحد مُفصح عنه في [مصدر البيانات](#مصدر-البيانات-وإفصاح) أدناه.

## لماذا يوجد هذا المشروع

اللهجة العراقية ممثّلة تمثيلاً ضعيفاً جداً في معالجة اللغة الطبيعية. أغلب البيانات
الحوارية العربية المتاحة تغطي الفصحى أو اللهجتين المصرية والشامية. توفّر هذي
المجموعة للنموذج تعرّضاً لمفردات وتراكيب عراقية (`شلونك` مو `كيف حالك`، `بيش` مو
`بكم`، `أكو` مو `يوجد`) بمجال — التفاوض التجاري — غائب تماماً عن المدوّنات العربية
العامة.

## مصدر البيانات وإفصاح

كل ملف تصنيف مولّد بالقوالب وبنك مفردات/أسماء منسّق — **باستثناء واحد يجب معرفته
قبل استخدام هذي البيانات**:

`iraqi_training_data/iraqi_train_04_cars_plus_scraped.json` يحتوي 10,832 سجلاً، منها
**832 سجلاً يحمل حقل `real_data` ورابط `source` يشير لإعلانات حقيقية محددة على
`sooq.iq` و`opensooq.com`** (ماركة/موديل/سنة/عداد/سعر/مدينة حقيقية، ورابط مباشر
للإعلان الأصلي). هذي ليست صناعية — سُحبت من إعلانات سوق حقيقية ومباشرة واستُخدمت
كحقائق تأسيسية للحوار المحيط بها. نفس الإعلانات المسحوبة، بروابط مصدرها، موجودة
أيضاً في `scraped_data/`.

هذا يعني:

- ادعاء "صناعية بالكامل" **لا ينطبق** على هذا الملف تحديداً — 832 من أصل 10,832
  سجلاً فيه (7.7%) تتضمن بيانات وروابط إعلانات حقيقية من طرف ثالث.
- الإعلانات كانت منشورات سوق عامة وقت السحب، لكن إعادة نشرها حرفياً (بما فيها
  روابط مباشرة لإعلانات فردية) أمر مختلف عن توليد نص صناعي، وعلى المستخدمين
  التعامل مع هذي المجموعة الفرعية بشكل مختلف — مثلاً استبعاد حقلي
  `real_data`/`source`، أو حذف الـ832 سجلاً، إذا احتجت مجموعة بيانات صناعية بحتة.
- لم يُعثر على أي أرقام هواتف أو أسماء بائعين أو معلومات تواصل شخصية أخرى، لا
  بالملفات المسحوبة ولا بملفات التصنيفات أثناء المراجعة (عدد من أرقام الهواتف
  بنمط أرقام وهمية مثل `07801234567` و`07800000000` يظهر بثلاثة ملفات تصنيف، وهي
  أرقام قوالب وهمية، مو أرقاماً حقيقية).

إذا احتجت مجموعة فرعية صناعية بحتة، استخدم `iraqi_train_04_cars.json` (10,000 سجل
مولّد بالكامل) بدل `iraqi_train_04_cars_plus_scraped.json`، أو صفِّ السجلات التي
فيها مفتاح `real_data`.

## الحدود

- **التوليد الصناعي.** باستثناء الحالة المُفصح عنها أعلاه، المحادثات منتجة
  بسكربتات وقوالب مغذّاة بمفردات وبنوك أسماء منسّقة — مو منقولة من متحدثين
  حقيقيين. تعكس أنماط حوار معقولة، لكنها مو كلاماً طبيعياً موثّقاً، وتفتقر لتعثرات
  الحديث الحقيقي.
- **تكرار القوالب.** الـ210,832 سجلاً تنهار إلى 171,601 تسلسل رسائل فريد حرفياً
  (1.23× إجمالاً). التكرار متفاوت: التصنيفات العشرة الأصلية للبيع تبقى دون 1.2×،
  بينما عدة تصنيفات عامة أُضيفت لاحقاً تصل 1.4–1.77×. راجع الجدول أعلاه قبل افتراض
  تنوّع منتظم.
- **تحيّز لمجال واحد.** قوة المجموعة الأساسية هي التفاوض التجاري بالبيع؛
  التصنيفات العشرة غير التجارية المُضافة لاحقاً أقل تطويراً نسبياً وأكثر تكراراً.
- **تغطية اللهجة محدودة بأصناف إقليمية معينة.** اللهجة الأساس بغدادية، مع مفردات
  من `word.json` تغطي مدناً عراقية إضافية (الموصل، البصرة، النجف، كربلاء وغيرها)،
  لكن الاستخدام البغدادي هو الغالب؛ اللهجات الجنوبية والشمالية ممثَّلة تمثيلاً
  أضعف. اللهجات غير البغدادية غير مميَّزة بحقل `dialect` — كل سجل موسوم
  `iraqi_arabic` بغض النظر عن مفردات أي مدينة يستخدم.
- **لا يوجد تقييم بشري للطبيعية.** لم يُجرَ أي تقييم من متحدث أصلي لطلاقة أو
  واقعية أو أصالة اللهجة بهذي المدوّنة؛ فقط فحوصات آلية ومراجعة ذاتية أثناء
  التوليد.
- **غير مفلترة للنشر.** ما فيها تدريب على الرفض أو مقاومة المدخلات العدائية.
- **الأسعار مرتبطة بزمنها** وتعكس ظروف السوق حوالي 2025–2026.

# Iraqi Arabic Sales Dialogue Dataset

## Dataset Summary

**210,832 template-generated conversations, of which 171,601 (81%) are exact-unique
message sequences (1.23× overall repetition)**, in colloquial Iraqi (Baghdadi-based)
Arabic across 20 topical categories. The core of the dataset (10 categories, roughly
100,000 records) is retail sales dialogue — price inquiry, haggling, warranty, and
closing a sale. A further 10 categories cover everyday and social domains (health,
education, government, restaurants, transport, sports, family, occasions,
neighborhood life, work).

The data is synthetically generated by template and generation scripts, not
transcribed from real speakers, with one disclosed exception: 832 of the 10,832
records in the cars-plus-scraped file embed real listing data and source URLs
scraped from `sooq.iq` and `opensooq.com`. See **Data provenance** below before
using that file.

## Supported Tasks

- Fine-tuning conversational / instruction-following LLMs for Iraqi Arabic
- Retail/sales chatbot development for Iraqi electronics, automotive, and
  real-estate businesses
- Arabic dialect identification and dialect NLP research
- Studying sales and negotiation discourse patterns

## Languages

Iraqi Arabic (`ar`, Baghdadi-based dialect, informal/colloquial register). Not
Modern Standard Arabic. Vocabulary draws on additional Iraqi cities (Mosul, Basra,
Najaf, Karbala, and others) but Baghdad usage dominates. The dataset's `dialect`
field is a constant (`iraqi_arabic`) and does not distinguish sub-varieties.

## Dataset Structure

### Data Instances

```json
{
  "id": "electronics_sales_0001",
  "category": "sales_electronics",
  "dialect": "iraqi_arabic",
  "messages": [
    { "role": "user", "content": "أريد لابتوب Asus Core i7 بس غالي علي" },
    { "role": "assistant", "content": "بس قبل ما تروح، شوف هذا الموديل الثاني، عندنا تقسيط بدون فائدة على 3 أشهر" },
    { "role": "user", "content": "يعني أدفع شكد بالشهر؟" },
    { "role": "assistant", "content": "مقدم 299,000 والباقي قسطين متساويين" }
  ]
}
```

### Data Fields

- `id` (string): record identifier
- `category` (string): sales/topic category, e.g. `sales_electronics`
- `dialect` (string): constant `iraqi_arabic`
- `messages` (list): alternating `role` (`user`/`assistant`) and `content` (string,
  Iraqi Arabic text)

Prices appear inline in `content` as Iraqi Dinar (IQD) figures, not as a separate
structured field.

### Data Splits

This dataset does not ship a canonical train/validation split at the top level.
The 21 files in `iraqi_training_data/` are per-category, undivided. Pre-split,
deduplicated JSONL versions (`data/iraqi_train_v8_part*.jsonl` /
`data/iraqi_val_v8.jsonl`, and earlier v4–v7 versions) are provided separately for
users who want a ready-made train/val split; see the repository README for the
full file layout.

## Dataset Creation

### Curation Rationale

Iraqi Arabic is under-represented in Arabic NLP resources relative to Modern
Standard Arabic and higher-resource dialects such as Egyptian or Levantine. This
dataset targets a domain — retail sales negotiation — that is largely absent from
general Arabic corpora, using a synthetic generation approach seeded with a
manually compiled Iraqi dialect lexicon (`word.json`, 930 terms / 50 categories).

### Source Data

Generated by `scripts/generate_iraqi_data.py` (and later variant scripts) using a
vocabulary bank derived from `word.json` and hand-authored templates for
conversational structure, product catalogs, and pricing ranges.

**Disclosed exception:** `iraqi_train_04_cars_plus_scraped.json` additionally
incorporates 832 records built from real, scraped car listings (brand, model, year,
mileage, price, city, and a direct source URL) pulled from `sooq.iq` and
`opensooq.com`. These are marked with a `real_data` field and a `source` URL in
that file, and the raw scraped listings are also included under `scraped_data/`.
Exclude records containing a `real_data` key, or use `iraqi_train_04_cars.json`
instead, if a strictly synthetic dataset is required.

### Annotations

Not applicable — no human annotation layer beyond the author's own review during
data generation.

### Personal and Sensitive Information

No phone numbers, seller names, or other personal contact details were found
during review. A small number of placeholder-pattern phone numbers (e.g.
`07801234567`, `07800000000`) appear in three category files; these are templated
placeholders, not real numbers. The 832 scraped car-listing records (see above) do
carry real prices, mileage, and city names tied to public marketplace posts, and a
direct URL to the original listing — this is public commercial listing data, not
personal data about an identifiable individual, but is disclosed here for
transparency since it is not synthetic.

## Considerations for Using the Data

### Social Impact and Biases

The dataset over-represents Baghdadi dialect and commercial/retail discourse.
Models trained on it alone will imitate a salesperson persona, including on
questions or requests it should decline, since no refusal or safety training is
included.

### Limitations

- **Synthetic generation.** With the disclosed exception above, all conversations
  are template- and script-generated, not transcribed from real speakers.
- **Template repetition.** 210,832 records collapse to 171,601 exact-unique message
  sequences (1.23× overall); repetition ranges from 1.02× (electronics) to 1.77×
  (restaurant) across categories — see the repository README for the full
  per-category table.
- **Single-domain bias** toward retail sales; the 10 non-commercial categories
  added later are less developed and more repetitive.
- **Dialect coverage** is skewed toward Baghdadi Arabic; other Iraqi regional
  varieties are under-represented and not distinguished in the data.
- **No human evaluation of naturalness** — no native-speaker fluency or realism
  rating has been performed on this corpus.
- **Not safety-filtered** for deployment as a general-purpose assistant.
- **Prices are time-bound**, reflecting market conditions around 2025–2026.
